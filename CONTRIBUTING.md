## Contributor License Agreement

To keep the Project's licensing flexible over time, all contributors must agree
to the [Contributor License Agreement](CLA.md) (CLA). The CLA lets the Maintainer
relicense the Project in the future (for example, to move it fully to an open
source license, or to offer a commercial license) without needing to track down
every past contributor.

By opening a pull request, You confirm that You have read the CLA and that You
agree to its terms for Your contribution.

### How agreement is recorded

For now, opening a pull request counts as agreement to the CLA. If the Project
grows, we plan to automate this with a CLA bot (such as CLA Assistant), which
asks each new contributor to sign once and records the signature on the pull
request.

## Making a change

1. Open an issue first for anything non-trivial, so we can align on direction.
2. Keep pull requests focused on a single change.
3. Make sure the project builds and the tests pass before You submit.
